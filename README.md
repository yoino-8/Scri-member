# Scri-memberとは？
データの外部送信や生成AIを通すことなく使える、各種脚本・台本のセリフ暗記のためのWebサイト（Webアプリ）です。
PDFファイルを読み込むことで使用できます。
- テキスト抽出はJavaScriptで機械的に行っているため、生成AIにデータが盗まれる心配はありません
- 読込まれた台本は保存されず、Webページを閉じたり再読み込みしたりすると消えます。

## 重要：利用される方へのお知らせ（最終更新：2026.11.23）
- 使い方は必ずお読みください。
- 縦書きの文字化けデータについて、デフォルトの変換表にない怪しいデータを発見した場合はご一報ください
  -　プログラム中で変換できていない怪しいデータはUnicode表示する使用になっていますので、そちらを教えていただけますと幸いです  
- 不具合・ご要望などあれば何なりとお申し付けください。

# 対応規格
PDF形式ファイル　かつ
  - テキストデータがあるもの（画像を貼り付けただけものは非対応）
  - 日本語のもの（他の言語は動作確認ができていません）  
  - セリフ表記が以下の形式の物(例：佐藤というキャラの「お腹すいた」というセリフ)
    -  佐藤　お腹すいた
    -  佐藤「お腹すいた」
  -  横書き・縦書き
    -　縦書きの文字化けバグは縦書きバグ修正ボタンの利用でおおよそ解消可能です

# 使い方
1. 右上の「PDF読み込み」ボタンを押し、読み込む台本を選択
2. 読み込み完了したら、暗記する役名の選択と設定
     - 色々な設定が出ますが、デフォルト設定＋縦書きバグ修正ONでOKです。
       - 詳細は後述（→こまごまとした設定達の説明 / 縦書きバグ修正について）
     - 再読み込みで変更が消えます、あしからず 
4. 「練習スタート」ボタンを押す
     - PDFプレビュー画面が表示されます（タイトルページは正常に表示されない場合があります）
     - 読み込み後に設定を変更したい場合は、設定を変更した後にもう一度「練習スタート」ボタンを押してください
5. 暗記したいページ、セリフを選択
     - ページは相手のセリフボックスの真上にある部分から数値入力またはボタンで変更できます
       - 右矢印ボタンで1ページ進み、左矢印ボタンで1ページ戻ります
     - PDFプレビュー画面において、赤い四角で囲まれているところが現在のセリフです
       - 任意のセリフをクリックすることで開始位置を自由に調整できます
6. ページ最下部の「進む」ボタン or ⇒キー を押して流れに沿って暗記
     - ひとつ前に戻りたいときは「戻る」ボタン or ⇐キーを押してください

### 細々とした設定達の説明
 - （）で始まる行はト書きとして扱うか選択できます
 - 行末が短い行（Wordのshift+Enter改行など）の次の行を、新しい項目として区切るか選択できます
   - 入力時にうっかり改行をshift+Enterにしてしまって、改行が改行として認識されない場合があるためです 
 - 読み取り結果を自由に閲覧できます

### 縦書きバグ修正について
 - 縦書きのPDFをコピーすると、文字化けが生じることがあるため、暫定的に修正するボタンをつくってあります
   - 例: 「会ったりしないのぉ？」→「会Yたりしないの×？」 
 - 縦書きバグ修正は、一部英文字にも影響が出てしまうためご注意ください
     - 縦書きバグ修正で変換されるものは変換表から自由に閲覧・修正できます
